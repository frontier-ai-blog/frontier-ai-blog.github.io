# Adding an article

1. Copy one of the sample HTML files in this folder and give it a descriptive lowercase filename.
2. Update its title, description, date, category, heading, summary, and article body.
3. Keep `article.css` and `article-page.js` linked so navigation, responsive styling, and theme selection continue to work.
4. Add one matching object to `catalog.js`. The Blog homepage renders and searches that catalog automatically.

The supported `visual` values are `boundary`, `systems`, `control`, `evaluation`, `memory`, `reliability`, and `handoff`.

Sample pages are explicitly marked with a sample-content notice. Remove that notice when replacing a placeholder with published content.
