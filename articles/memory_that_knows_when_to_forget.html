Memory That Knows When to Forget

Why useful agent memory depends as much on deletion and scope as it does on recall.

Frontier AI for Office Science / Jul 18, 2026

Sample content: This placeholder demonstrates the article template and can be replaced when a published draft is ready.

More memory is not always more context

Persistent memory can reduce repetition, but irrelevant history can crowd out the information that matters now. The system must decide what belongs to the person, the project, the task, or only the current turn.

Good memory is governed by provenance and expiration. Every retained fact should have a source, a scope, and a reason to remain available.

Forgetting is a product capability

Deletion should be predictable and inspectable. People need ways to correct stale assumptions and understand what the system will carry into future work.

  • Separate durable preferences from temporary state.
  • Expire inferred facts more aggressively than explicit ones.
  • Let users inspect and remove retained information.
